# Security policy

## Supported versions

PdfBuilder is pre-release. Security fixes are applied to the latest development branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use the repository owner’s private GitHub contact channel and include a minimal, sanitized reproduction, affected version, impact, and suggested mitigation where known.

Do not include sensitive PDFs, fonts, credentials, or customer data. You should receive an acknowledgement within five business days.
